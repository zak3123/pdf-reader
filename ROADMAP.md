# LitePDF Roadmap

## Version 1

- Reliable local PDF reading.
- Recent documents.
- Resume page.
- Bookmarks.
- Dark interface.
- Efficient rendering.

## Version 2

- Page thumbnails.
- Search using a more capable PDF engine.
- Password entry for encrypted PDFs.
- Horizontal or paged reading modes.
- Table of contents and PDF links.
- Improved zoom rendering.

## Version 3

- Optional PDFium or MuPDF engine.
- EPUB and CBZ support if licensing permits.
- Annotations and highlights.
- Text selection.
- Printing and sharing selected pages.

Some future features require replacing or extending Android `PdfRenderer`, especially password entry, full-text search, text selection, outlines, links, and higher-quality zoom rendering.
